<objective>
Close the phase: prove every plan's work holds together simultaneously, then restore
`git.branching_strategy` to `milestone` as the final commit.

The gate matters because Plans 03, 04, and 05 ran in one wave and Plan 06 in the next. Each
verified itself, but three phase-level invariants only become checkable once all of them have
landed: the loop-matrix invariant can only see the complete set of async test modules at the end,
the full suite only exercises every new fixture together at the end, and the cassette digest only
proves no plan wrote to the cassette tree once every plan has run.

TOOL-01 is deliberately last (D-18). Flipping the setting re-arms the commit helper's branch
auto-switching, which derives a branch name from project state and switches to it at commit time —
the exact behaviour that stranded commits during Phase 44 and the reason the setting was turned
off. Doing it earlier would migrate this phase's own task commits mid-flight. There is a second
layer to that hazard this plan has to handle directly: the flip and the commit of the flip happen
in the same task, so a commit made through the tooling right after the edit would itself read the
new value.

Purpose: one honest look at the whole phase, then the single-key revert.
Output: a recorded gate result and the restored setting.
</objective>
