<objective>
Migrate the Snowflake and DuckDB introspectors off native drivers onto the Engine's ADBC pool,
rewire `Query.execute()`/`using()` and the codegen CLI to resolve Engines, finalize the public
surface, and delete the now-dead native `*_connect_kwargs` helpers (D3, D5; the migration
breadth from CONTEXT). The Snowflake `SHOW COLUMNS IN VIEW` path is live-spike-proven identical
over ADBC; DuckDB's two-pass DESCRIBE moves to the pool with the `semantic_views` extension
loaded via the connect-event. Databricks introspection is handled separately under the gated
Plan 04 — this plan ships the Snowflake+DuckDB critical path.

Purpose: Complete the unification — every introspector and the runtime query path now flow
through one owned ADBC pool. This closes the "two parallel worlds" from RESEARCH.
Output: ADBC-only Snowflake + DuckDB introspect(); `query.execute()` via `get_engine`; CLI via
`create_engine`; deleted `snowflake_connect_kwargs`/`databricks_connect_kwargs`; `__init__`
exporting `create_engine`/`get_engine` and dropping `pool_from_config`/`get_pool`.
</objective>
