<objective>
Lay the Wave 0 test bedrock for the Engine-owns-the-pool redesign. This plan rewrites the
existing unit tests and shared fixtures to express the NEW connection contract
(`create_engine`, `register("name", engine)`, `get_engine`, ADBC-cursor introspection) so that
the implementation plans (02, 03, 04) have failing tests to satisfy. No production code changes
here — this is the test-first scaffold the Validation Architecture (44-VALIDATION.md) requires.

Purpose: Per CLAUDE.md's failing-test-first rule and 44-VALIDATION.md Wave 0 gaps, the new API
needs its test surface to exist before the production rewrite. The Snowflake/DuckDB/registry
mocks today stub native drivers via `sys.modules`; those stubs encode the OLD path and must be
replaced with an ADBC-cursor seam.
Output: Updated `test_registry.py`, `test_pool.py`, `test_snowflake_engine.py`,
`test_duckdb_engine.py`, `test_config.py`, and the `tests/conftest.py` /
`src/semolina/conftest.py` fixtures — all RED against current `main` (expected), GREEN after
Plans 02–03 land.
