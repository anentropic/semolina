<objective>
Prove the whole codegen annotation path end to end on one column, then make the two
seams that path depends on safe for every later plan in this phase.

The tracer is a single DuckDB `DECIMAL` metric carried from a live in-memory warehouse
through `Engine.introspect` -> `duckdb_type_to_python` -> `_build_model_context` ->
`python_model.py.jinja2` -> `render_and_format`, and asserted on the emitted source. It
delivers TYPE-03 for DuckDB and TYPE-04 for every backend in one slice, because a
`decimal.Decimal` annotation is unusable without an `import decimal` and a `T | None`
annotation is unusable if it suppresses `import datetime`.

Purpose: the renderer's import mechanism is currently two booleans computed by exact
string membership on the *raw* introspected type. Every remaining plan in this phase adds
an annotation that mechanism cannot express (`decimal.Decimal`, `JsonValue`, `T | None`).
Proving the replacement on one column first means a wrong shape costs one commit, not ten.

Output: a DuckDB `DECIMAL` key in the type map, a generalised import-emission path, metric
nullability per Decision 2, a raw-warehouse-type comment channel per D-03, Phase 47's
artifact regenerated and its canary re-pointed per D-10, and a runnable scope-fence gate.
</objective>
