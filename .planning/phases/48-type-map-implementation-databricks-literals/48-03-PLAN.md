<objective>
Finish the type map: the Decimal policy on Snowflake and Databricks, concrete Python types
for every category-1 map gap, and a `JsonValue` union for VARIANT.

48-01 proved the whole path on one DuckDB column. This plan applies the same policy to the
remaining backends and the remaining gaps, so that a decimal column annotates identically on
all three backends (SC1), no category-1 type still emits a `TODO:` placeholder (SC3), and a
VARIANT column yields a union rather than `Any` (SC3).

Purpose: this is the public annotation contract. Phase 49's `.into(DTO)` and Phase 50's
codegen'd DTOs build on the exact strings this plan writes, and changing them later breaks
every committed generated model. That is why the annotation table earns a blocking
confirmation checkpoint after it lands.

Output: `FIXED` -> `decimal.Decimal` for the whole family with the scale test deleted;
`decimal` -> `decimal.Decimal` on Databricks; DuckDB `DECIMAL`/`UUID`/`JSON`/`ENUM`/
`TIMESTAMP_S|_MS|_NS` keys and `HUGEINT` corrected; a Databricks `interval` branch reading
`start_unit`/`end_unit`; a `semolina.JsonValue` alias exported and wired into the renderer's
import emission; `47-TYPE-FIDELITY.md` regenerated; DuckDB `INTERVAL` recorded as a broken
window.

**Deliberate structure note.** Tasks 1 and 2 are rated `one-way` and the confirming checkpoint
(Task 3) sits AFTER them, not before. The plan-structure check warns about that ordering; the
inversion is intentional and the orchestrator's reversibility brief calls for it. The mapping
was already chosen by the user and locked as D-03 / D-05 / D-06 in `48-CONTEXT.md`, so what is
owed is confirmation that the table in the code matches the table that was locked — which can
only be checked once it is in the code. A `checkpoint:decision` before Task 1 would re-open a
decision the user has already made. If the checkpoint rejects a row, the correction is a
one-line dictionary edit plus a snapshot and artifact regeneration, all inside this plan and
before anything else in the phase consumes the contract.
</objective>
