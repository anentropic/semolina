<objective>
Build the two pieces `--check` cannot exist without: a result-schema probe that ships, and
an Arrow-type-to-Python-annotation function that does not exist anywhere in the repo.

`probe_schema` currently lives in `tests/type_fidelity_probe.py`, and a shipped CLI cannot
import from the test tree. `arrow_type_to_python` has no implementation at all —
`--check` compares a committed Python annotation against a `pyarrow.Schema`, so one of the
two has to be translated, and Phase 50's DTO-07 needs the same function.

Purpose: separating these from the CLI keeps them testable without a CLI runner, and keeps
Phase 50 from re-deriving them. It also protects Phase 47's anti-circularity defence at the
new location: the probe's whole point is that it resolves a schema WITHOUT Semolina's type
map, and a promotion that quietly imported the map would make the evidence artifact a
restatement of the thing it measures.

Output: `src/semolina/codegen/probe.py` and `src/semolina/codegen/arrow_map.py`, both
first-class documented tested modules; `tests/type_fidelity_probe.py` re-importing rather
than duplicating; a circularity guard at the new location; and a re-read of the Databricks
ADBC driver's `ExecuteSchema` answer at the pinned version.
</objective>

  <action>
Create `src/semolina/codegen/arrow_map.py`. Structure it exactly like its sibling
`type_map.py`, in this order: a module docstring stating the contract AND what a miss means,
`from __future__ import annotations`, `import pyarrow` and `import pyarrow.types` at module

Signature: `def arrow_type_to_python(dtype: pyarrow.DataType) -> str | None:`. Returning
`str | None` rather than raising is deliberate and matches the three SQL mappers: an unknown
TYPE is an open vocabulary the user can resolve by hand, so it returns `None` and the caller
constructs its own `TODO: {dtype}` string — exactly as the three engines already do. (Contrast
`_field_class_for`, where an unknown ROLE raises, because roles are a closed vocabulary.)

The body is an ORDERED `if pyarrow.types.is_*(dtype)` cascade, not a dict lookup: a
`pyarrow.DataType` is parameterised, so `decimal128(38, 2)`, `timestamp[us, tz=Europe/London]`
and `dictionary<values=string, indices=uint8, ordered=0>` have no stable key. Never match on
