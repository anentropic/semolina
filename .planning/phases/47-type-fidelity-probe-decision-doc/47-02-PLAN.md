<assumption_delta_decision>
**Noun now primary:** *the field's result type*. Warehouse introspection metadata was the single
source of truth for a field's Python type; the query-time result schema is now a second source.

**Decision: `promote`** — the result schema becomes primary, introspection metadata is demoted to
a labelled, offline-capable estimate of it. Not "add alongside": where the two disagree the result
schema wins, because `to_pylist()` converts from the result schema and never from the catalogue.

**Invariant encoding the intent:** the canary test from plan `47-01`, plus this plan's
per-disagreement tests. Each asserts a measured Arrow type by literal; a change that re-derives
the result column from the metadata column turns them red.

**Recorded in:** plan `47-04`, `47-DECISIONS.md`. Implemented in Phase 48, not here.
</assumption_delta_decision>
