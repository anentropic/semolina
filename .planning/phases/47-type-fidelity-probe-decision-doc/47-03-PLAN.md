source of truth for a field's Python type; the query-time result schema is now a second source.

**Decision: `promote`** — the result schema becomes primary, introspection metadata is demoted to
a labelled, offline-capable estimate. This plan is where the demotion becomes visible: the

reviewer scanning for that label finds circularity immediately.

`test_replay_schema_matches_raw_arrow_file` — if the artifact's result numbers ever start coming
from anywhere but the recording, the two reads diverge and the test goes red.

**Recorded in:** plan `47-04`, `47-DECISIONS.md`.
