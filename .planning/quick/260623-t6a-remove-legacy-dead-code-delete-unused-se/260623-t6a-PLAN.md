<objective>
Remove legacy dead code uncovered during the pytest-adbc-replay migration:

1. The unused `semolina.testing.credentials` module (`SnowflakeCredentials`,
   `DatabricksCredentials`, `CredentialError`) and its re-export from
   `semolina.testing`. Credentials now come from `[connections.*]` in
   `.semolina.toml` via `semolina.config.warehouse_config` / `pool_from_config`.
2. The legacy native `Engine.execute()` query path — the abstract method on the
   `Engine` base ABC and its concrete implementations in `SnowflakeEngine`,
   `DatabricksEngine`, and `DuckDBEngine` — plus the associated execute()-only
   unit tests. All documented query execution now flows through the ADBC pool
   path (`register()` + `Query.execute()`).

Purpose: Eliminate confirmed dead code so the engine surface is honestly
"introspection + SQL generation only".
Output: Smaller engine ABC (to_sql + introspect), no credentials module, green
quality gates.

KEEP intact: `introspect()`, `to_sql()` and all their tests; `Query.execute()`
and cursor `.execute(...)` calls (these are the supported runtime path, NOT the
removed `Engine.execute()`).
</objective>
